# Guide

Tools provides behaviors, helpers, components, model extensions, and utility classes for CakePHP applications. [Install the plugin](/guide/install), then follow [Getting started](/guide/quick-start) to load one helper and render a progress bar.

Load features where you use them. Tools Table, Entity, and Controller base classes are optional extensions; their reference pages describe the additional methods they supply.

| Area | Examples |
|---|---|
| [Behaviors](/behavior/) | Slug generation, string filters, password changes, bitmasks, and JSON fields |
| [Helpers](/helper/) | Progress and meter elements, typography, trees, and formatting |
| [Components](/component/) | Request trimming, mobile detection, and redirect targets |
| [Model and Entity](/model/) | Validation methods, related values in use, token storage, and enum options |
| [Reference](/reference/) | Mailers, login-link authentication, dates, URLs, error handling, and utilities |

## Existing applications

The [upgrade guide](/guide/upgrade) records changes from the previous CakePHP branch. Tools depends on [Shim](/guide/shims), which supplies compatibility helpers. The [Tools backend](/guide/backend) requires routes and application access controls.
